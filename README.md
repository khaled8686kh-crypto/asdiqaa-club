# برنامج إدارة فريق الأصدقاء الرياضي

ملف واحد `index.html` يعمل مباشرة على GitHub Pages أو Vercel.

## التشغيل التجريبي
افتح `index.html` في المتصفح كما هو — يعمل بدون Firebase وتُحفظ البيانات على نفس الجهاز فقط.

## ربط Firebase (للحفظ السحابي والمشاركة بين الإداريين)
1. من console.firebase.google.com أنشئ مشروعاً جديداً (مثلاً: asdiqaa-club).
2. **Build ← Realtime Database ← Create database** (اختر us-central1) وابدأ بـ Locked mode.
3. من تبويب **Rules** الصق محتوى ملف `database.rules.json` واضغط Publish.
4. **Build ← Authentication ← Get started ← Sign-in method ← Anonymous** فعّله (يحتاجه البرنامج للاتصال بقاعدة البيانات).
5. **Project settings ← Your apps ← Web (</>)** سجّل تطبيقاً وانسخ `firebaseConfig`.
6. افتح `index.html` وابحث عن `FIREBASE_CONFIG` والصق القيم مكان «ضع_هنا» (تأكد من وجود `databaseURL`).

## الدخول
- **الحساب الرئيسي:** رمز من 6 أرقام (الافتراضي 362801) — يمكن تغييره من صفحة «المستخدمون».
- **المستخدمون:** حتى 5 مستخدمين يضيفهم الحساب الرئيسي، كل مستخدم باسم مستخدم وكلمة مرور.
- **الصلاحيات:** الميزانية والاشتراكات يعدّلها الحساب الرئيسي والمدير المالي فقط.

## التحديث والنسخ الاحتياطي
- زر **🔄 تحديث البرنامج** في القائمة الجانبية يعيد تحميل آخر نسخة.
- عند رفع نسخة جديدة على GitHub يظهر للمستخدمين شريط «يتوفر تحديث جديد» خلال دقيقتين.
- صفحة **💾 النسخ الاحتياطي** (للحساب الرئيسي): تنزيل نسخة كملف، استعادة من ملف، ونسخة تلقائية يومية في السحابة (آخر 7 نسخ).
- عند تحديث القواعد الصق محتوى `database.rules.json` الجديد في Firebase ← Rules.

## الرفع
- **GitHub:** أنشئ مستودعاً جديداً (مثلاً asdiqaa-club) وارفع الملفات.
- **Vercel:** Add New ← Project ← اختر المستودع ← Deploy (بدون أي إعدادات إضافية).
- **أو GitHub Pages:** Settings ← Pages ← Branch: main / root ← Save.
- بعد الرفع أضف نطاق الموقع في Firebase: **Authentication ← Settings ← Authorized domains**.
